信号処理プログラミングの基礎

更新 2026-09-04 · Revision 2 · Evidence reviewed

概要

信号処理プログラミングとは、音声、センサー値、通信波形などを数値列として取り込み、時間領域・周波数領域の両方から測定、変換、除去、分類、可視化する技術である。最初に理解すべき流れは「測る（標本化）→配列として扱う→スペクトルを見る→目的に応じてフィルタする→結果を検証する」である。

この記事の見取り図

  1. 信号・標本化・振幅・周波数・位相を定義する。
  2. DFT/FFTとスペクトルの読み方を学ぶ。
  3. FIR/IIRフィルタ、畳み込み、時間周波数解析を使い分ける。
  4. Python実装の最小例と、エイリアシング・端点・スケーリングの注意点を確認する。

定義と全体像

離散信号を x[n]、標本化間隔を Ts​、標本化周波数を fs​=1/Ts​ とする。正弦波は、振幅 A、周波数 f、位相 ϕ を用いて

x(t)=Asin(2πft+ϕ)

と表せる。振幅は大きさ、周波数は変化の速さ、位相は基準に対するずれである。プログラムでは、値の配列と、それが何秒間隔で測られたかを必ず一組で管理する。

帯域制限された信号を元の信号として復元したい場合、標本化周波数は最高周波数の2倍を超える必要がある。これを満たさないと、周波数成分が別の低い周波数に折り返されるエイリアシングが生じ、後処理だけでは一般に復元できない[1][2]。

歴史的背景・古典的理解

通信工学では、Nyquistが1928年の論文で帯域幅とパルス伝送・符号間干渉の関係を論じ、後のサンプリング理論に連なる考え方を示した[3]。Shannonは1949年の論文で、雑音を含む通信を帯域・信号・雑音の関係として定式化した[4]。現在「Nyquist–Shannon標本化定理」と呼ばれる説明は、これらの通信理論、Whittakerの補間理論などを含む複数の系譜を統合したものとして理解するのが適切であり、Nyquistの1928年論文だけが連続信号の標本化・再構成を完成させた、と単純化してはいけない[3][5]。

現在の標準的理解

DFTとFFT

長さ N の離散フーリエ変換は

X[k]=n=0∑N−1​x[n]e−j2πkn/N

であり、逆変換は 1/N の係数を持つ。FFTはDFTを効率よく計算するアルゴリズムで、NumPyは基本的なFFT APIを、SciPyはより広い信号処理機能を提供する[1][2]。実数信号では、正負周波数が共役対になるため、rfftで非負周波数側だけを扱える。

フィルタと畳み込み

線形時不変フィルタは、入力とインパルス応答 h[n] の畳み込み

y[n]=k∑​x[k]h[n−k]

で表せる。FIRは有限長の係数で構成され、線形位相を設計しやすい。一方IIRは再帰を持ち、少ない係数で鋭い特性を得やすいが、安定性や位相の扱いに注意が要る[1]。用途が「特定帯域のエネルギーを見る」ならFFT、時間波形のノイズを抑えるならフィルタ、周波数が時間で変わる音や振動ならSTFTを候補にする。

最小実装例

import numpy as np
from scipy import signal

fs = 2000.0
t = np.arange(0, 1.0, 1 / fs)
x = np.sin(2 * np.pi * 120 * t) + 0.35 * np.sin(2 * np.pi * 700 * t)

# 300 Hz未満を通すFIRローパス
b = signal.firwin(numtaps=81, cutoff=300, fs=fs)
y = signal.lfilter(b, [1.0], x)

# 非負周波数の振幅スペクトル
X = np.fft.rfft(x)
freq = np.fft.rfftfreq(len(x), d=1 / fs)
amplitude = np.abs(X) / len(x)

この例では、配列xの時間間隔をfsと一貫させ、FIR係数を設計し、rfftでスペクトルを得ている。振幅の正規化、片側スペクトルでの係数補正、フィルタ端点の過渡応答は、測定値の定量比較では別途検証する必要がある[1][2]。

詳細説明

FFTのピーク位置は、信号に含まれる周期成分の候補を示す。ただし観測時間が有限なら周波数分解能は概ね Δf=fs​/N であり、窓関数を使わないと漏れが生じる。ゼロパディングは表示上の周波数グリッドを細かくできるが、観測情報そのものを増やさない。STFTは短い窓を時間方向に移動してFFTを繰り返す方法で、時間変化する周波数を見られる一方、窓長が長いほど周波数分解能が上がり、時間分解能が下がるというトレードオフがある[1]。

実装では、単位（Hz、秒、ボルトなど）、dtype、欠測値、NaN、配列軸、境界条件を明示する。データをフィルタした後は、元波形と処理後波形を重ね、スペクトル、残差、遅延、振幅変化を確認する。因果的なlfilterは未来の値を使わないが遅延を生み、ゼロ位相処理はオフライン解析には便利でもリアルタイム処理にはそのまま使えない。

応用・実践上の含意

音声では帯域分離・ノイズ抑制、振動では異常周波数の追跡、医用・環境センサーでは周期性と外れ値の検出に利用できる。実務の順序は、(1)センサー仕様と標本化条件の確認、(2)単位と欠測の整理、(3)生データの保存、(4)可視化、(5)最小の処理、(6)既知信号によるテスト、(7)性能評価である。フィルタのカットオフや窓長は「見た目が滑らか」だけで選ばず、検出したい時間幅・周波数幅・許容遅延から決める。

限界・論争点・未解決事項

理想的な帯域制限、無限長データ、完全なクロックは現実には成立しない。アンチエイリアス用のアナログ回路、量子化雑音、クロックジッタ、センサーの非線形性が結果に影響する。サンプリング定理を満たしていても、有限長観測・窓関数・雑音により推定誤差は残る。FIRとIIR、時間分解能と周波数分解能、平滑化とイベント保存には一般的な唯一解がない。したがって、処理前後のデータ、パラメータ、ソフトウェアバージョン、テスト信号を保存し、再現可能性を確保することが重要である。

まとめ

信号処理プログラミングの基礎は、標本化周波数と単位を正しく管理し、時間領域と周波数領域を往復しながら、目的に合う変換・フィルタ・可視化を検証することである。FFTは万能な「信号の意味の自動判定」ではなく、観測条件とモデルを含めて解釈するための計算手段である。
