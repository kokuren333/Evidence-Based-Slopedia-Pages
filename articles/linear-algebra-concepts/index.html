大学教養レベルの線形代数学：概念まとめ

図1　線形写像を中心に、ベクトル空間・行列・構造解析・近似・応用の関係を示した概念図。[1][2][3][5]

概要

線形代数学は、足し算とスカラー倍を保つ写像（線形写像）を、ベクトル空間・基底・行列を通じて理解する分野である。[1][2][3] 教養レベルでは、連立一次方程式から核と像、固有値、直交射影、最小二乗、特異値分解（SVD）へ進むと、計算と構造を一つの体系として捉えられる。

この記事の見取り図

  1. ベクトル空間が対象と演算の共通言語を与える。
  2. 基底と座標が抽象的対象を数値で表す。
  3. 行列が線形写像と連立方程式を結び付ける。
  4. 核・像・ランクが解の構造を、固有値が不変な方向を示す。
  5. 直交性・最小二乗・SVDが近似と応用へ橋を架ける。

定義と全体像

ベクトル空間とは、ベクトルの加法とスカラー倍が定義され、分配法則などを満たす集合である。実数ベクトルだけでなく、多項式や関数も例になる。[2][3] 線形結合 c1​v1​+⋯+ck​vk​ は空間内の対象を生成する。

基底は、空間を生成し、線形独立なベクトルの組である。有限次元では基底の本数を次元といい、基底を選ぶと各ベクトルを一意な座標で表せる。[2][3]

線形写像 T:V→W は T(u+v)=T(u)+T(v)、T(cv)=cT(v) を満たす。基底を固定すれば線形写像は行列 (A) で表され、Ax=b は写像の出力が b になる入力を問う式になる。[1][2]

歴史的背景・古典的理解

連立一次方程式の研究は、行列概念より先に存在した。古代中国の算術書には、係数を配列して消去する方法に近い計算が見られる。[4] 19世紀には、Gauss、Cauchy、Sylvester、Cayleyらを通じて、行列式・行列・線形変換が整理された。Sylvesterは1850年に matrix という語を用い、Cayleyは行列を独立した代数的対象として扱った。[4]

歴史的に行列式が中心だった時期もあるが、現代の入門教育では、行列を線形写像の表現として抽象的ベクトル空間と統合する。[2][3][4]

現在の標準的理解

連立一次方程式と行列

行基本変形は解集合を保ちながら Ax=b を階段形へ変換する。解がない、一意、無限という違いは、ランクと自由変数で説明できる。[2][3]

核・像・ランク

核 kerT は T(v)=0 となる入力、像 ImT は到達可能な出力の集合である。有限次元では階数・退化次数定理

dimV=dimkerT+dimImT
が成り立つ。[2][3]

固有値・固有ベクトル

ゼロでない (v) が Av=λv を満たすとき、v を固有ベクトル、λ を固有値という。写像で方向が保たれる特別な方向を表す。[1][2] ただし実行列が常に実固有値をもつとは限らず、複素数体が必要な場合がある。[1]

内積・直交性・最小二乗

内積は長さと角度を定義し、直交射影を可能にする。Ax=b が厳密に解けない場合、残差 ∣b−Ax∣2 を最小にする解を求めるのが最小二乗法である。[2][3] これは近似であり、モデルの正しさや因果関係を保証しない。

特異値分解（SVD）

SVDは実行列または複素行列を A=UΣV∗ に分解し、直交（複素ではユニタリ）変換と非負の特異値で伸縮と主要方向を分離する。[2][5] 低ランク近似、最小二乗、画像処理などに有用だが、精度は特異値の減衰、ノイズ、スケーリング、条件数に依存する。

詳細説明

線形代数学の概念は公式の寄せ集めではない。基底を変えると行列表示は変わるが、ランク、固有値、可逆性など写像に結び付く性質は適切な意味で保たれる。したがって、計算時には「どの基底で、何を表す行列か」を確認する。

行列式は正方行列の可逆性や符号付き体積変化を調べる道具である。一方、数値計算では行列式の直接計算が安定とは限らず、QR分解、SVD、ピボット付き消去を使い分ける。[2][5]

応用・実践上の含意

線形代数学は、回帰、データ圧縮、画像処理、信号処理、物理・工学、機械学習の基盤になる。[2][3][5] 学習では、小行列の手計算、幾何的な図示、核・像・ランクの言語化、残差と条件数を伴う数値検証を往復するとよい。

限界・論争点・未解決事項

線形モデルは非線形現象をそのまま表すものではなく、局所近似や特徴量設計を要する場合がある。固有値分解は非対称行列では直交対角化できないことがあり、SVDやSchur分解などが必要になる。[1][2] 最小二乗や低ランク近似は計算上の最適性を与えても、データの偏りや因果関係を解決しない。無限次元空間、作用素論、数値安定性の厳密な扱いは発展課題である。

まとめ

線形代数学の中心は、ベクトル空間上の線形写像を基底と行列で表現し、核・像・固有構造・直交構造を調べることにある。連立方程式は解の構造を、固有値は不変な方向を、最小二乗とSVDは近似の構造を明らかにする。「対象・写像・表現・不変量・近似」の対応を追うことが概念理解の要点である。
